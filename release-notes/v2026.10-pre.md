OPM Flow for Windows — native MSVC build (hybrid MPI + OpenMP) with a Qt GUI workbench.

**Downloads** — the installer and the portable zip both work for most people; pick whichever you prefer.
- `OPM-Flow-2026.10-pre-Setup.exe` — installer: adds Start-menu shortcuts. The Visual C++ and OpenMP runtimes ship inside the package, so the only external prerequisite is **Microsoft MPI** (the simulator links `msmpi.dll`); the installer installs it for you if it's missing.
- `opm-flow-2026.10-pre-win64.zip` — portable: unzip and run `bin\flow-gui.exe`. The Visual C++ and OpenMP runtimes are already in `bin\`; the only thing you might need is **Microsoft MPI** — if it isn't already installed, run `redist\msmpisetup.exe` once (or `winget install Microsoft.msmpi`).
- `OPM-Flow-2026.10.0.0.msix` — unsigned MSIX (for sideloading/Store experiments; see PACKAGING.md). **Note:** Windows will not enable its **Install** button unless the signing certificate is already trusted on the machine (it shows *"Publisher: Unknown / this app package's certificate could not be verified"*).
- `opm-flow-gui-0.3.2-ubuntu24.04-x86_64.tar.gz` — **Linux** build of the GUI (Ubuntu 24.04 LTS, all tabs enabled). No `flow` is shipped for Linux — see the **Linux** section below.

**Contents:** `flow.exe` (all model variants, including black-oil; built from current OPM master plus the pending Windows patches) and `flow-gui.exe` **0.3.2** — a full workbench:
- **Full speed on modern laptops** — both `flow` and the simulators flow-gui spawns now opt out of Windows "EcoQoS" power throttling, which otherwise clocks background processes down dramatically (a serial Norne measured 1.6× slower without the exemption — including MPI ranks, which Windows always treats as background).
- **Run tab** — job queue with live progress/ETA, Stop/Skip, deck validation (`--enable-dry-run`), re-run of an already-finished queue (after confirmation), View PRT / View DBG / Open result folder, and a developer *Simulator* override to test your own `flow` build.
- **Results tab** — summary-vector plotting straight from `SMSPEC`/`UNSMRY`: grouped/filtered vector picker with human-readable names, multi-case comparison with per-case markers, zoom, date axis, PNG export; plots refresh live while a run is writing.
- **3D View tab** — the corner-point grid colored by static (INIT) or dynamic (UNRST) properties incl. synthesized SOIL, well trajectories colored by type, report-step animation, auto-framed default view.
- **Projects** — save/load the whole session (queue, run options, cases) as a readable `.opmproj` file.
- **Deck Editor tab** — section tree over the deck and its INCLUDE files with Eclipse syntax highlighting; edits are saved to the original files.

flow-gui is cross-platform (the same sources build on Linux and macOS). Upgrading from the previous pre-release: the GUI executable was renamed from `flow-gui-qt.exe` to `flow-gui.exe`, and saved GUI settings/queue reset once due to the rename.

**Linux**

- **Run the Ubuntu binary** — unpack `opm-flow-gui-0.3.2-ubuntu24.04-x86_64.tar.gz`, install the runtime packages, run:
  ```bash
  sudo apt install libqt6charts6 libqt6openglwidgets6t64 libfmt9
  ./opm-flow-gui-0.3.2-ubuntu24.04-x86_64/flow-gui
  ```
  Built on Ubuntu 24.04 LTS against the distro Qt; expected to also work on later Ubuntu releases.
- **Bring your own simulator** — unlike the Windows package, we do not release `flow` for Linux. Install or build OPM Flow following [opm-project.org](https://opm-project.org/?page_id=36) (e.g. the OPM binary packages: `sudo apt install mpi-default-bin opm-simulators`), then point the *Simulator:* field on the Run tab at it once (e.g. `/usr/bin/flow` or your own `.../opm-simulators/bin/flow`) — remembered between sessions.
- **Other distros: build flow-gui yourself** — it is a small standard CMake + Qt 6 project:
  ```bash
  sudo apt install qt6-base-dev qt6-charts-dev libfmt-dev cmake ninja-build g++
  git clone https://github.com/GitPaean/opm_flow_windows
  cmake -S opm_flow_windows/flow-gui -B build-gui -DCMAKE_BUILD_TYPE=Release \
        -DFLOWGUI_OPM_PREFIX=<opm-common install prefix>
  cmake --build build-gui
  ```
  The Results and 3D View tabs need an opm-common install prefix at configure time (watch for `flow-gui summary plotting: ON` / `3D viewer: ON`); without it you still get the Run tab and deck editor. Full recipe including the opm-common step: [flow-gui/README.md → Building → Linux](https://github.com/GitPaean/opm_flow_windows/blob/master/flow-gui/README.md#linux).

**Getting past SmartScreen (this build is unsigned)**
The binaries are not code-signed, so Windows shows *reputation* warnings — these are not virus detections, and for the `.exe`/`.zip` they are dismissible:
- **When downloading** (Edge/Chrome): if it says *"… isn't commonly downloaded"* and the download stops or shows **Canceled**, open the download's **⋯ (More actions)** menu → **Keep**, then **Keep anyway**.
- **On first launch**: if *"Windows protected your PC"* appears, click **More info → Run anyway**.

**Notes**
- Windows 10/11 x64; the Linux GUI tarball targets Ubuntu 24.04 LTS or later (x86_64).
- Parallel runs: `mpiexec -n <ranks> flow.exe DECK.DATA --threads-per-process=<threads> --output-dir=<dir>`, or use the GUI.
